Artifacts CLI

bun install -g @tarileo/artifacts-cli
npm GitHub skills.sh

Usage

# One daemon serves all projects (port 7000)
artifact init                 # once per project
artifact create <slug>      # scaffold docs/artifacts/<slug>/
artifact start               # daemon + dashboard at /p/<id>/
artifact start --tailscale   # expose on your Tailnet
artifact list / artifact stop
artifact reload <slug>

Each artifact lives in docs/artifacts/<slug>/ as a standalone index.html. The dashboard renders them isolated and reloads on save.

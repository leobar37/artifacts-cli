Artifacts CLI

bun install -g @tarileo/artifacts-cli
npm GitHub skills.sh

Uso

# En un proyecto con docs/artifacts/
artifact start              # servidor + dashboard (puertos 7000-7100)
artifact start --tailscale  # exponer en tu Tailnet
artifact list / artifact stop --all
artifact reload <slug>

Cada artifact vive en docs/artifacts/<slug>/ como index.html o content.tsx. El dashboard los muestra aislados y recarga al guardar.

Skill para agentes

bunx skills add leobar37/artifacts-cli

Concepto Clave

Vercel AI SDK maneja la UX del chat (input, output, streaming). Claude Code SDK ejecuta las acciones (leer archivos, escribir, ejecutar comandos). El backend actúa como puente entre ambos.

Claude Code SDK

Motor de tool calling que corre headless y ejecuta acciones reales

query()

Tareas puntuales

  • Sesión única, sin estado
  • Async iterator de mensajes
  • Ideal para automation 
for await (const msg of query({...})) {
  // procesar
}

ClaudeSDKClient

Sesiones persistentes

  • Mantiene estado entre msgs
  • Interrupts y hooks
  • Ideal para chat apps 
const client = new ClaudeSDKClient({...});
await client.send("mensaje");
await client.send("otro mensaje");

Flujo Completo

Paso a paso de una interacción típica

1

Usuario selecciona artifact

Click en artifact → Se carga en iframe → Chat obtiene contexto del artifact

2

Usuario escribe en chat

Input → useChat → POST /api/chat con { message, slug, artifactContext }

3

Backend recibe y procesa

Valida request → Inyecta system prompt con artifact context → Inicia Claude SDK session

4

Claude Code SDK ejecuta tools

ClaudeSDKClient.send() → Tool: Read (lee artifact) → Tool: Write (modifica) → Result

5

Archivo se modifica en disco

docs/artifacts/{slug}/index.html se actualiza → chokidar detecta cambio

6

SSE notifica al frontend

Watcher → sseRegistry.broadcast('artifacts:update') → useArtifactEvents → refetch

7

Artifact se recarga

iframe src refreshes → Chat muestra resultado de la operación → Usuario ve cambios

1 ChatPanel Component (Frontend) 

import { useChat } from 'ai/react';

export function ChatPanel({ artifact }: { artifact: Artifact }) {
  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat({
    api: '/api/chat',
    body: {
      slug: artifact.slug,
      artifactPath: artifact.path,
      artifactType: artifact.type
    }
  });

  return (
    <div className="flex flex-col h-full">
      <div className="flex-1 overflow-y-auto">
        {messages.map(=> (
          <ChatMessage key={msg.id} message={msg} />
        ))}
      </div>
      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          disabled={isLoading}
          placeholder="Pregunta sobre el artifact..."
        />
      </form>
    </div>
  );
}

2 API Route con Streaming (Backend) 

import { streamingText } from 'ai';
import { ClaudeSDKClient } from '@anthropic-ai/claude-code-sdk';

const client = new ClaudeSDKClient({
  cwd: process.cwd(),
  allowed_tools: ["Read", "Write", "Edit"],
  permission_mode: "bypass"
});

export async function POST(req: Request) {
  const { message, slug, artifactPath, artifactType } = await req.json();

  const systemPrompt = `
    Eres un asistente especializado en artifacts HTML.
    Artifact actual: ${slug}
    Tipo: ${artifactType}
    Ruta: ${artifactPath}
    El usuario puede pedirte que modifiques el artifact.
  `;

  return streamingText({
    model: client,
    system: systemPrompt,
    prompt: message,
    onChunk: ({ chunk }) => chunk
  });
}

3 Claude SDK Wrapper Service 

import { ClaudeSDKClient, AssistantMessage, TextBlock, ToolUseBlock } from '@anthropic-ai/claude-code-sdk';

export class ClaudeService {
  private clients = new Map<string, ClaudeSDKClient>();

  getClient(slug: string, cwd: string) {
    if (!this.clients.has(slug)) {
      this.clients.set(slug, new ClaudeSDKClient({
        cwd,
        allowed_tools: ["Read", "Write", "Edit", "Bash"],
        permission_mode: "bypass"
      }));
    }
    return this.clients.get(slug)!;
  }

  async sendMessage(slug: string, message: string, context: ArtifactContext) {
    const client = this.getClient(slug, context.cwd);
    const fullPrompt = `[Context: ${context.type} artifact at ${context.path}] ${message}`;

    const response = await client.send(fullPrompt);
    return this.parseResponse(response);
  }

  private parseResponse(msg: AssistantMessage) {
    let text = "";
    for (const block of msg.content) {
      if (block instanceof TextBlock) text += block.text;
      if (block instanceof ToolUseBlock) text += `\n[Tool: ${block.name}]`;
    }
    return text;
  }
}
